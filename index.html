游客数据存本地，登录后一键合并到云端，换设备也不丢。

FAQ

常见问题

需要注册账号才能听歌吗？

不需要。浏览、搜索、榜单、歌单和在线播放对游客全部开放，收藏与历史存在本地；注册只为云同步、评论点赞等能力服务。

服务器地址怎么改？

首次启动会引导填写服务器地址，之后可在「我的 → 设置 → 服务器地址」随时修改，无需重新编译安装。地址可填局域网地址（如 http://192.168.1.10:8000）或公网 HTTPS 域名。

iOS 安装包为什么不能直接装？

发布的是未签名 ipa。云真机 / 云测平台上传时会由平台重新签名；安装到自己的手机请用 Sideloadly、AltStore 等工具自签。

Android 装不上或提示有风险怎么办？

真机请下载 arm64 包，模拟器 / 云手机请选择 universal 包。系统拦截时允许「未知来源」安装即可，安装包由 GitHub Actions 自动构建。

音频资源会被盗链吗？

音频与封面接口使用带时效的签名地址，过期即失效；建议服务端配合私有存储桶使用。

源码在哪里？

App 端在 LCS6-SDWL/yin，Go 后端在 LCS6-SDWL/yunyun-server，两个仓库相互独立。
